\# ADR-0001



\## Title



Use Git with Feature Branches



\## Status



Accepted



\## Context



The project requires version control that supports experimentation without destabilizing production code.



\## Decision



Use:



\- main

\- dev

\- feature/\*



Workflow:



feature → dev → main



\## Consequences



Pros



\- Safe development

\- Easier reviews

\- Professional workflow



Cons



\- Slightly more Git knowledge required
