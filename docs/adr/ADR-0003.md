\# ADR-0003



\## Title



VS Code as Source of Truth



\## Status



Accepted



\## Context



Roblox Studio binary projects are difficult to version control.



\## Decision



All source code is authored in VS Code.



Roblox Studio is used for:



\- testing

\- building maps

\- animations

\- debugging



Rojo synchronizes the project.



\## Consequences



Pros



\- Git-friendly

\- AI-friendly

\- Modular

\- Easier reviews
