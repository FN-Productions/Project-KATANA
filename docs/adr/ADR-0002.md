\# ADR-0002



\## Title



Animation Driven Combat



\## Status



Accepted



\## Context



Project KATANA focuses on satisfying melee combat.



\## Decision



Combat timing is controlled by animations.



Hitboxes activate during animation keyframes.



Combat is timing-based rather than physics-based.



\## Consequences



Pros



\- Better game feel

\- Fair parry timing

\- Easier balancing



Cons



\- Requires higher-quality animations
